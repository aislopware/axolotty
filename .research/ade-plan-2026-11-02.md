# ADE expansion plan (2026-11-02)

The owner asked for five things:
- a layout that doesn't repeat itself;
- colours built from Dracula Pro;
- every OSC that matters, with Rex-level terminal features but our own UI;
- deep shell integration;
- remote windows.

This plan comes from five research passes, all retrieved 2026-11-02:
- ADE layouts and features: Warp, cmux, herdr-app, Conductor, Paradev, Zed, Ghostty 1.4, iTerm2 3.7.
- Shell integration in seven terminals.
- Dracula Pro, its licence and how apps build chrome from it.
- Rex and the libghostty-vt OSC coverage.
- Remote design, in `remote-2026-11-02.md`.

Each unit below is one commit.

## 1. Colours: Night and Day, built the Dracula Pro way

**Licence.** Colour values can't be copyrighted, but the Pro EULA binds a buyer. So the palette is derived, not copied:
- The Pro method is public: HSL with saturation 100 and lightness 75 for accents, and a ramp at the 250° hue for grounds.
- The Pro hues are public in Dracula's site CSS.
- The Alucard accents are public in the MIT spec and in dracula/zed.

It keeps our own names (Axolotty Night and Day) and credits Dracula (MIT).

## 2. Layout: say each thing once

The band no longer repeats the selected sidebar row:
- **With the sidebar open**, the band drops "project › program title". It keeps what the row doesn't show: the branch with its diff, the host (once remote exists), and the state chip or timer.
- **With the sidebar hidden**, the band brings the identity back, because nothing else shows it.

This follows herdr-app, Paradev, Conductor and Warp: none of them repeats the row's title in the top bar. Pane strips stay split-only.

## 3. Terminal protocol: everything libghostty-vt hands the embedder

- **Answers:**
  - DA1 `?62;22;52c` (52 only while clipboard writes are allowed) and DA2 `>1;10;0c`. DA3 and ENQ stay silent.
  - XTVERSION "Axolotty <version>", plus the terminfo name for XTGETTCAP TN.
- **Size reports:** XTWINOPS 14, 16, 18 and 19, and in-band mode 2048. They use the size driver's cell metrics.
- **Colour scheme:** CSI ?996n answers from the appearance, and mode 2031 sends a report unasked when the appearance flips.
- **Clipboard read** (OSC 52 `?` and Kitty 5522): off by default; a setting allows it. Kitty paste events come with it.
- **Pointer shape** (OSC 22): the client reads it from its mirror and sets the cursor.
- **Synchronized output** (mode 2026): the client holds the frame while a program draws, with a timeout.
- **Unknown OSCs:**
  - OSC 633, VS Code's shell integration, is mapped to the same marks as 133.
  - OSC 1337 SetUserVar is kept per pane, if libghostty reports it to us.
- **Kitty graphics:** images drawn from libghostty's placements, in a later unit.

## 4. Shell integration

### Scripts (zsh, bash, fish, nushell)
- OSC 133:
  - `A;cl=line;aid=`;
  - `P;k=s` on PS2;
  - `redraw=last` for bash;
  - `D;<code>` with the code first.
- OSC 7 on every prompt, with control bytes stripped.
- A bar cursor at the prompt, then a reset for the command.
- Title: the shortened directory at the prompt, the command while it runs.
- An `ssh` wrapper that installs terminfo once per host and otherwise falls back to xterm-256color, and forwards `TERM_PROGRAM`.
- `sudo` keeps `TERMINFO`.
- Don't double-mark when fish 4 or nushell already emit 133 themselves.

### Terminal side
- Option-click moves the cursor at a prompt.
- ⌘-triple-click selects a command's output. "Copy Output of Last Command" is in the menu.
- Marks in the scroll gutter, red for a failed command; hover shows the code, duration and directory.
- Closing at a prompt doesn't ask.
- "Run Recent Command" and "Go to Recent Directory" palettes, kept per host.
