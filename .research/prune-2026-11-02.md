# Prune, 2026-11-02

**The rule.** We follow Amp: "If we don't use and love a feature, we kill it." There is no
backcompat and nothing legacy. A feature that goes is deleted, not hidden in the palette or
behind a setting, and when it's unclear, it goes. ([Amp manual](https://ampcode.com/manual))

**The result.** Branch `prune` against `main`: 71 files changed, +601 and −3916 lines. There are
20 commits, one per area. `swift test` passes. A second look the same day brought six things back (below).

## Second look (2026-11-02, the owner: "too much went")

The first pass asked "is there another way?" The second asked "does anyone who works this way do without it?", checking each cut against Ghostty 1.4, iTerm2 3.7, cmux, herdr-app and the Claude Code docs. Six cuts failed that test and came back:

| Brought back | Why |
|---|---|
| ⌥⌘-arrow focus, ⌃⌘-arrow resize, ⌃⌘= Equalize | These are defaults in Ghostty and iTerm2, and cmux and herdr have the directional focus keys. With only ⌘[ ⌘], a 2×2 grid becomes a walk. |
| Finish toasts while the app is in front | The old rule already skipped panes on screen. The cut also silenced a finish in a session you can't see, and that's the case a toast is for. |
| Every installed agent on "+" | herdr's "+" lists every installed agent, keyed 1–9. The list only ever showed agents found on PATH. |
| The long-command notice (≥ 10 s, not editors, REPLs or agents) | It's the shell's version of an agent finishing. Ghostty (`notify-on-command-finish`) and iTerm2 (Alert on Next Mark) both have it, opt-in. |
| `axolotty attach` | The app connects only to this Mac, so attach is the one way to reach a running agent from another terminal or another Mac. cmux and herdr-core both have one. |
| ⇧⌘T resumes the Claude conversation | cmux reopens with `claude --resume <id>`. Reopening as a bare shell lost the conversation, the one thing worth reopening. The id comes from `claude agents --json` at close time, which is documented and reads no files. `--continue` was tried and dropped: it takes the folder's latest conversation, which may be another session's. |

Some cuts held up under the same test:
- copy on select, because Ghostty's macOS default is `none`;
- cursor settings, because the bar and dimming blink are designed and programs set the shape with DECSCUSR;
- `notify`, because Codex and Gemini post over OSC 9, which Axolotty shows;
- pin and unread, because drag order and done-until-seen cover them;
- ports, because ⌘-click opens the URL;
- the Changes popover, because it was an inspector.
